Why these Canvas choices?

One exit: Back leaves the form; a changed draft gets a discard confirmation. A second Cancel action is useful in a dialog without clear navigation, but redundant in this screen. The principle is a clear exit, not a mandatory extra button.

Focused fields, live bottom estimate & input guardrails: All form boxes share a crisp outline and type-aware examples. Market search opens a searchable popup dialog that filters to valid ticker/company characters (`A–Z`, `0–9`, `.`, `-` — since Tokyo/Hong Kong/Shanghai tickers like `7203.T`, `0700.HK`, `600519.SS` and funds like `S&P 500` include digits alongside alphabetical tickers), while Quantity accepts positive fractional decimals only (`> 0`). For assets, Estimated value starts at `0` (`₹0` / `$0`) pinned directly above Save, without a redundant Current / After net-worth block below the form.

60 characters: a proposed product limit for custom names and required holding names. It allows descriptive labels while keeping lists readable. The counter counts user-perceived characters; fetched company names are not truncated.

Ready to save: required fields must be valid; a quote is optional so offline entry still works. Selecting a market holding fetches once automatically, without waiting for a quantity. Bonds keep the app's current manual-value model, not an invented ticker lookup.

Holdings first: names, tickers, and values are the reading experience. The small group menu holds name/value sorting and an explicit Arrange manually view; reorder arrows never occupy the normal list. Switching sorts does not erase your custom arrangement. Values are compared in the base currency; unpriced holdings stay last.
